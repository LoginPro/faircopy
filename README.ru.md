# FairCopy

![FairCopy](Branding/logo.png)

**Приватный офлайн ИИ-редактор для любого поля ввода на Mac.** Выдели текст (или просто поставь курсор в поле сообщения), нажми <kbd>⌃⌥R</kbd> — и получи чистовик: опечатки, пунктуация и слитный поток слов исправлены, а разговорный тон, сленг и эмодзи остались как были.

*Fair copy* — по-английски «чистовик». FairCopy делает чистовик из каждого сообщения: идея — как у ИИ-редактора Telegram, но работает в любом приложении и целиком на твоём Mac через [LM Studio](https://lmstudio.ai). Без облака и аккаунтов — текст не покидает компьютер.

[English version](README.md) · **Windows:** порт — в папке [`windows/`](windows/README.ru.md) (в разработке).

## Что умеет

- **Исправление** — орфография, пунктуация, заглавные буквы, слитный текст. Текст *не* становится официальным: «щас», «норм», мат и эмодзи остаются.
- **Стилизация** — Официальный, Краткий, Дружеский, Вежливый, Корпоративный, Племенной, Дзен, Библейский, Викинг, **Без паразитов** (убирает «ну / короче / типа / как бы») или любой стиль своими словами.
- **Перевод** — на 10 языков, можно со стилем поверх.
- **Понятные правки** — удалённое красным, добавленное синим; наведи на правку — увидишь правило.
- **Ручная правка** результата перед вставкой, затем <kbd>⌘↩</kbd>.
- **Мгновенная замена** — <kbd>⌃⌥⇧R</kbd>, без окна.
- **Память по приложениям** — Telegram открывается в «Кратком», Почта — в «Официальном».
- **Редактор стилей** — менять, переставлять, удалять и создавать стили (инструкция + примеры «было → стало»), проверять прямо в настройках; стандартные можно восстановить.
- **Мой стиль** — стиль по твоим собственным сообщениям (вставкой или экспортом Telegram Desktop в HTML/JSON): переписывает любой текст так, как сказал бы ты.
- **Личный словарь** — имена и термины, которые нельзя «исправлять».
- **Прогрев и выгрузка модели** из строки меню.
- Интерфейс на Liquid Glass, русский и английский язык; промпты — на языке интерфейса.

## Требования

- macOS 26+, Apple Silicon (проверено на M4, 24 ГБ)
- [LM Studio](https://lmstudio.ai) с локальным сервером
- Модель — по умолчанию **Gemma 4 12B** (MLX, 4-bit QAT, ~9 ГБ); полегче — Qwen 3.5 9B
- Xcode Command Line Tools (полный Xcode не нужен)

Дальше — шаги 1–2 ниже и модель:


## Сборка из исходников

```bash
~/.lmstudio/bin/lms get https://huggingface.co/mlx-community/gemma-4-12B-it-qat-OptiQ-4bit
git clone https://github.com/LoginPro/faircopy.git
cd faircopy
./build.sh install
```

Затем:

1. **Универсальный доступ**: Системные настройки → Конфиденциальность и безопасность → Универсальный доступ → включить *FairCopy*.
2. **Токен LM Studio** (если сервер требует авторизацию): LM Studio → Developer → Server Settings → Manage Tokens → Create Token, потом меню FairCopy → «Токен LM Studio…». Хранится в Связке ключей.

**Подпись.** `build.sh` подписывает приложение локальным сертификатом `AI Editor Local Signing`, если он есть, иначе — ad-hoc. С ad-hoc подписью Универсальный доступ придётся выдавать заново после каждой сборки. Чтобы этого избежать, создай самоподписанный сертификат для подписи кода (Связка ключей → Ассистент сертификации → Создать сертификат…, тип «Подпись кода») и укажи его имя: `SIGN_ID="Имя" ./build.sh install`.

## Горячие клавиши

| Сочетание | Действие |
|---|---|
| <kbd>⌃⌥R</kbd> | Окно редактора для выделенного (или всего поля) |
| <kbd>⌃⌥⇧R</kbd> | Исправить и заменить сразу |
| <kbd>↩</kbd> / <kbd>⌘↩</kbd> | Применить (⌘↩ при ручной правке) |
| <kbd>⌘R</kbd> | Ещё раз |
| <kbd>esc</kbd> | Закрыть |

Сочетания меняются в Настройки → Основное. Командная строка и устройство проекта описаны в [английском README](README.md#command-line).

Все промпты и стандартные стили лежат в папке [`shared/`](shared/) в виде JSON, а не в коде: версия для другой ОС будет использовать ровно те же формулировки.
